# ブラウザ麻雀

ブラウザで遊べる4人打ち麻雀です。ゲーム本体は**単一のHTMLファイル**(`index.html`)で、インストールも通信も要りません。スマホ(縦・横)にも対応し、ホーム画面に追加してオフラインでも遊べます。

▶ **遊ぶ: https://tg2032.github.io/mahjong/**

## 遊び方
- あなたは画面下の席。座席は反時計回りで、右が下家・上が対面・左が上家です。
- 「対局開始」→ サイコロを振って親を決めます。
- 捨てたい牌をクリック(スマホ・タッチは **1回タップで選択、もう一度タップで打牌**)。ツモ牌は右端に金枠で表示され、`T` キーまたは「ツモ切り」で切れます。
- ポン・チー・カン・ロン・ツモ・リーチは中央下のボタンで選びます。鳴ける牌には枠が付き、ボタンに触れると実際に使う牌が強調されます。
- 手牌欄の「💡ヒント」で、おすすめの牌と理由(牌効率・打点・放銃の危険度・押し引き)を表示できます。
- ヘッダの「ルール」で、ルールやCPUの強さ、ヒントの出し方を変えられます(ルールは対局開始時に確定)。
- 対局は各局の開始時に自動保存されます。ブラウザを閉じても、開き直すと「続きから」で再開できます(その局は配牌からやり直し)。
- スマホでは、ブラウザのメニューの「ホーム画面に追加」でアプリのように使えます(PWA。一度開けば、通信なしでも遊べます)。

## 実装しているルール
| 区分 | 内容 |
|---|---|
| 対局 | 東風戦 / 東南戦(半荘)。25000点持ち。延長戦(30000点未満なら 南入・西入)。トビ終了。オーラスの親の和了止め・聴牌止め |
| 牌 | 赤ドラ(5萬・5筒・5索 各1枚)、ドラ・裏ドラ・カンドラ |
| 役 | 一般役一式(リーチ・一発・平和・断幺九・三色・一通・チャンタ・七対子 など)、ダブルリーチ、嶺上開花、海底・河底、槍槓、人和 |
| 役満 | 国士無双、四暗刻、大三元、大四喜・小四喜、字一色、清老頭、緑一色、九蓮宝燈、四槓子、天和・地和。ダブル役満(国士十三面・四暗刻単騎・純正九蓮宝燈・大四喜) |
| 鳴き・槓 | ポン、チー、大明槓、暗槓、加槓、リーチ後の暗槓(待ちが変わらない場合のみ)、喰い替え禁止 |
| ロン | ダブロン / 頭ハネ(選択)、三家和は流局。フリテン(自分の河・同巡・リーチ後) |
| 流局 | 荒牌平局(ノーテン罰符)、流し満貫、九種九牌・四風連打・四家立直・四槓散了 |
| 精算 | 本場・供託、責任払い(大三元・大四喜)、切り上げ満貫(選択) |

ルール設定で選べる項目: 対局の長さ / ダブロン・頭ハネ / 人和(満貫扱い・役満・なし) / オーラスの親の連荘 / 延長戦 / ダブル役満 / 切り上げ満貫 / 責任払い / トビ / 赤ドラ / 喰い替え禁止 / 流し満貫 / 途中流局。

## CPUとヒント
- **CPU**: 弱い(ミスが多い)/ 普通 / 強い。
  「強い」は、ヒントと同じ評価エンジン(受け入れ枚数→和了率・想定打点・放銃の危険度・押し引き)で、打牌・リーチ・鳴きを決めます。
- **ヒント**: 現物・スジ・字牌・壁から放銃率を概算し、他家のリーチには「オリ/押し」を提案。リーチかダマかの助言と、鳴けるときのポン・チー・パスの推奨も出ます。
- 強さの目安(ツモ切りだけのダミー1人+CPU3人、各200局での平均順位。小さいほど強い): 強い 1.87位 / 普通 2.17位。

## 開発
`index.html` が本体です(HTML・CSS・JavaScriptを1ファイルに収めています)。ビルド手順はありません。`manifest.webmanifest`・`sw.js`・`icon-*.png` は、ホーム画面に追加・オフライン対応のための補助ファイルです(アイコンは `node tools/make-icons.js` で再生成できます)。

### テスト
Node.js 18 以上で、画面なしにゲーム本体を読み込んで検証します(外部ライブラリ不要)。

```bash
npm test            # 通常(ランダム総当たり8局。1〜2分)
npm run test:full   # ランダム総当たり60局
node tests/run.js rules   # 名前の一部で絞り込み
```

| テスト | 内容 |
|---|---|
| `selftest` | ゲーム内蔵の自己診断(和了判定・役・符・喰い替え など) |
| `yaku` | 役の判定と点数表(子/親・ロン/ツモ・役満・ダブル役満) |
| `rules` | 人和・天和・ダブロン・流局・延長戦・パオ・加槓/槍槓 などの個別シナリオ |
| `hint` | ヒントの妥当性(孤立牌・オリ・押し・鳴き判断) |
| `resume` | 対局の自動保存・「続きから」での再開・壊れた保存データの無視 |
| `keys` | キーボード操作(←→・Enter・T・H・P・Esc)と牌の読み上げ名 |
| `design` | 見た目の指定の固定(白は無地・赤ドラの区別・動きを減らす設定への配慮) |
| `pwa` | マニフェスト・アイコン・Service Worker の整合性 |
| `fuzz` | ルール・CPUの強さ・操作をランダムに組み合わせた全局で、牌の総数・手牌枚数・点数の保存を毎手検査。画面の文言に内部コードや `undefined` が漏れていないかも検査 |

GitHub Actions(`.github/workflows/test.yml`)で、push のたびに自動実行されます。

### CPUの強さの測定
```bash
node tests/tools/tournament.js 2,1,1 100   # 座席1=強い、座席2・3=普通、座席0=ダミー。100局
```
座席ごとのレベルは `S.levels`(内部用)で指定します。AIの改良は、この測定で効果を確かめてから採用しています。
